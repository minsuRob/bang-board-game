# 구현 기준 룰

원작 룰북을 그대로 옮기지 않는다. 여기에는 **코드가 실제로 어떻게 판단하는지**와
**어디에 그 판단이 들어 있는지**를 적는다. 규칙을 고칠 때 여기부터 본다.

애매한 항목의 결정과 근거는 `edge-cases.md` 의 「애매해서 결정이 필요한 항목」에 있다.

## 한 차례의 뼈대

`engine/frames/turn.ts` 가 차례마다 이 순서로 프레임을 쌓는다.

```
turnStart → (revealEvent) → eventTurnStart → drawPhase → playPhase
          → discardPhase → turnEnd → checkWin → advanceTurn
```

- `playPhase` 와 `discardPhase` 는 **멈추는 프레임**이다. 이 둘이 스택 맨 위에 있는 동안
  엔진은 해결을 멈추고 액션을 기다린다 (`engine/stack.ts` 의 `isBlocked`)
- `revealEvent` 는 하이 눈을 쓸 때, **보안관의 두 번째 차례부터** 공개된다
- `eventTurnStart` 는 그 시점에 걸린 훅을 모아 순서대로 쌓는다.
  발동 순서는 `Modifier.order` 가 정한다: 새로운 신분(1) → 하이 눈(5) → 다이너마이트(10) → 감옥(20)
- 감옥에 걸리면 `skipRestOfTurn()` 이 이번 차례의 `drawPhase`·`playPhase`·`discardPhase` 를
  스택에서 걷어낸다. `turnEnd` 는 남기므로 차례는 정상적으로 넘어간다
- 액티브 플레이어가 자기 차례에 죽어도(자기가 건 결투에서 패배 등) `playPhase` 는
  더 이상 멈추지 않는다. 멈추면 아무도 둘 수 없는 교착이 된다

## 뱅! 한 장의 흐름

`engine/frames/combat.ts`

1. `bang` 프레임이 서고, 아직 판정을 안 돌렸으면 `onTargetedByBang` 훅을 먼저 쌓는다
   (술통·주르도네. 둘 다 있으면 판정 기회는 두 번)
2. 판정이 ♥ 면 `creditDodge()` 가 스택 아래의 `bang` 프레임에서 요구 빗나감을 1 줄인다
3. 요구가 0 이 되면 빗나갔다고 기록하고 끝
4. 아니면 표적에게 빗나감을 요구한다. 낼 카드가 없으면 묻지 않고 바로 피해
5. 미제출 시 `damage` 프레임

요구 장수는 `outgoingBangMissesOf()` 가 정한다 (슬랩 더 킬러 2).
**기관총은 뱅! 카드가 아니라 뱅! 효과**라서 이 값을 쓰지 않고 언제나 1이며,
차례당 뱅! 횟수도 소비하지 않는다.

## 피해와 탈락

`engine/frames/damage.ts`

```
damage → onDamaged 훅 → (목숨 0 이하면) checkDeath
       → 생존맥주 → eliminate
       → onEliminated 훅(벌쳐 샘) → eliminateCleanup → bountyOrPenalty → checkWin
```

- **목숨은 음수까지 내려간다.** 0 에서 자르면 다이너마이트로 -2 가 됐을 때
  살아나는 데 필요한 맥주 수를 잘못 세게 된다
- 생존맥주는 **생존자가 3명 이상**일 때만 묻는다. 유령은 생존자로 세지 않는다
- 살아날 가능성이 아예 없으면 묻지 않는다 (맥주가 모자라고 시드 케첨도 못 쓸 때)
- `source` 는 반격 능력(엘 그링고)이 향하는 가해자, `credit` 은 현상금·벌칙을 받는 사람이다.
  자기가 신청한 결투에서 지면 `source` 는 없고 `credit` 만 있다
- 탈락 처리 순서는 **벌쳐 샘 회수 → 현상금 → 보안관 벌칙 → 승리 판정**으로 고정한다

## 판정 (카드 펼치기)

`engine/frames/judgement.ts` — 함수가 아니라 프레임이다.

- 들여다보는 장수는 `judgementPeekOf()` (러키 듀크 2). 두 장이면 입력을 기다린다
- 무늬는 언제나 `effectiveSuit()` 을 지난다. 축복은 전부 ♥, 저주는 전부 ♠ 로 덮어쓴다
- 고르지 않은 카드도 버린 더미로 간다
- 다이너마이트는 ♠2~9 면 폭발(목숨 3), 아니면 다음 사람에게. 방향은 골드러시를 따른다
- 감옥은 ♥ 면 탈출, 아니면 차례를 통째로 건너뛴다. 카드는 어느 쪽이든 버려진다

## 거리

`engine/distance.ts`

- 자리에 앉아 있는 사람만 원에 넣는다. 탈락자는 빠지고, **유령은 남는다**
- 시계/반시계 중 짧은 쪽 + 표적 쪽 가산(야생마·폴 리그렛) − 보는 쪽 감산(조준경·로즈 둘란)
- 결과는 1 아래로 내려가지 않는다
- 뱅!은 사정거리 안에서만. 강탈은 **무기를 무시하고** 거리 1 이내

## '생존자 수' 와 '링 참여자 수'

둘은 다른 개념이다. 유령도시가 이 둘을 갈라놓는다.

| 쓰이는 곳 | 기준 |
|---|---|
| 맥주의 2인 규칙, 승리 판정 | 생존자 수 (`alivePlayers`) |
| 거리 계산, 잡화점이 펼치는 카드 수 | 링 참여자 수 (`seatedPlayers`, 유령 포함) |

## 카드를 낼 수 있는가

`engine/legal.ts` 의 `legalActions()` 하나가 판단한다. UI 하이라이트·AI 후보·리듀서 검증이
전부 이 함수를 쓴다. 세 곳이 각자 판단하면 반드시 어긋난다.

- 치환(칼라미티 자넷)은 `canUseCardAs()` 를 지난다. 치환해도 뱅!은 차례당 제한을 받는다
- `canPlayCard(..., reactive)` 의 `reactive` 는 '사용'이 아니라 '버림'이라는 뜻이다.
  결투 응수와 인디언 대응이 여기 해당하고, 설교·수갑은 이를 막지 않는다
- 맥주는 생존자가 2명이면 아예 낼 수 없다 (아무 효과가 없으므로)
- 감옥은 보안관에게, 그리고 자기 자신에게 쓸 수 없다
- 강탈·캣 발루는 **자기 앞의 카드**를 겨눌 수 있다 (자기 다이너마이트를 치우는 용도)
- 같은 이름의 파랑 카드를 두 장 장착할 수 없다. 무기는 갈아 끼우면 이전 것이 버려진다

## 손패가 비는 순간

수지 라파예트는 손패가 비는 **모든 경로**에서 울려야 한다. 특정 시점에 매달지 않고
`stack.ts` 의 `sweepHandEmpty()` 가 해결 루프마다 훑는다.

단 하나의 예외로, **결투가 진행 중이면 발동하지 않는다.** 응수로 마지막 뱅!을 낸 직후
곧바로 보충하면 결투가 끝나지 않는다.

## 능력 훅

`engine/modifier.ts` 가 끼어들 수 있는 지점을 전부 모아 둔 곳이다.
엔진 코어는 캐릭터 id 를 검사하지 않는다. 조회는 언제나 런타임이다 (`hooks.ts`).

숙취는 캐릭터 훅을 통째로 걷어낸다. 그래서 능력을 끄는 규칙이 16곳에 흩어지지 않는다.

## 제한시간

온라인에서만 쓰이지만 **규칙의 일부로 못박는다.** 기본 행동이 비결정적이면 리플레이가 깨진다.
`reducer.ts` 의 `defaultAction()` 이 그 값을 정한다.

- 반응 → 반응하지 않음. 단 러키 듀크의 판정만 유리한 쪽을 자동 선택
- 카드 사용 단계 → 차례 마치기
- 버리기 단계 → 첫 카드 버리기
