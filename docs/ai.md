# AI — 역할 추론과 역할별 판단

코드: `src/game/ai/`. 추론은 `belief.ts`, 카드 점수는 `policy.ts`, 난이도 분기는 `index.ts`,
상 난이도 시뮬레이션은 `hard.ts`.

## 원칙

- **보이는 것만 본다.** AI 는 `viewFor` 로 가려진 상태만 받는다. 감춰진 역할은 `'outlaw'` 로
  마스킹되어 있으므로 `p.id === me || p.roleRevealed` 를 확인한 뒤에만 `p.role` 을 읽는다.
- **기억을 따로 두지 않는다.** 매 결정마다 `view.log` 를 처음부터 다시 읽는다.
  온라인에서 AI 를 굴리는 사람이 도중에 바뀌어도 같은 국면이면 같은 판단이 나온다.
- **결과가 아니라 의도를 센다.** 빗나간 뱅!도 보안관을 노렸다는 사실은 같다.

## 증거

| 로그 | 해석 | 세기 |
|---|---|---|
| `playCard` 뱅!·결투 (대상 있음, 자넷의 빗나감=뱅! 포함) | 대상을 쳤다 | 1.0 |
| `playCard` 감옥 | 대상을 쳤다 | 0.8 |
| `panic`·`catBalou` (장비가 아닌 것을 가져감) | 대상을 쳤다 | 0.6 |
| `panic`·`catBalou` 로 감옥·다이너마이트를 떼어 줌 | 대상을 **도왔다** | 0.8 |
| `playCard` 기관총·인디언 | 누구를 노렸는지 모른다 | anti 0.1 |
| `bounty` | 무법자를 처치했다 (무법자끼리도 받는다, EC-55) | law 0.3 |

누구를 쳤느냐에 따라 방향이 정해진다.

- 보안관을 쳤다 → 보안관의 적 쪽 증거. `threatToSheriff` 가 오른다
- 드러난 무법자·배신자를 쳤다 → 보안관 편 쪽 증거. 탈락해 드러난 역할은 **지난 사격에도 소급**한다
- 정체 모를 사람을 쳤다 → 그 순간 대상이 보인 성향 × 0.7 만큼만.
  초반의 어림짐작 사격은 약한 증거이고, 보안관을 쏜 사람을 쏜 것은 '돕는' 증거가 된다
- 보안관의 행동은 증거로 쓰지 않는다 (보안관도 추측하며 쏜다)

증거 점수 `law`·`anti` 를 역할별 가능도로 바꾼다.
양쪽을 다 치는 것이 배신자의 지문이다.

```
deputy   = law − 1.5·anti
outlaw   = anti − 0.8·law
renegade = 0.9·min(law, anti) + 0.2·law − 0.3·anti
```

## 난이도 = 읽는 깊이

| 난이도 | 추론 (`InferDepth`) | 실수 |
|---|---|---|
| 하 | `direct` — 시간 순서대로 읽는다. 남은 역할 수는 사전확률로만 | 70% 확률로 아무 수. 단 **같은 편을 해치는 수는 빼고** 고른다 |
| 중 | `full` — 판 전체에서 드러난 성향으로 지난 행동을 다시 읽고, 남은 역할 묶음을 나눠 주는 모든 경우를 따진다 | 20% |
| 상 | `full` + 그 분포대로 역할을 지어내 결정화 몬테카를로 | 없음 |

상 난이도의 시뮬레이션 안에서 상대는 `public` (공개된 역할과 남은 역할 수만) 으로 둔다.

## 역할별 판단

적대도는 상대가 각 역할일 확률로 가중한 기댓값이다 (`hostility`).

- **보안관**: 무법자 > 배신자(무법자가 남아 있으면 절반) . 부관일 가능성은 크게 뺀다 (부관을 쏘면 손패·장비를 전부 잃는다).
  확신이 없는 상대에게는 뱅!보다 감옥을 선호한다
- **부관**: 보안관을 겨눈 사람을 먼저 막는다. 보안관이 다치면 주점, 갇히면 감옥을 떼어 준다.
  보안관 목숨이 1 이면 기관총·인디언을 쓰지 않는다
- **무법자**: 보안관이 최우선. 보안관을 쏜 사람은 동료로 보고 치지 않는다.
  보안관 목숨이 1 이면 기관총·인디언이 결정타다
- **배신자**: 세력 균형을 본다 (`renegadeHostility`)
  - 보안관 목숨이 2 이하 → 보안관을 도와 무법자를 친다
  - 그 밖에는 강한 쪽을 친다. `edge` = 무법자 전력 비율 − 0.5 일 때
    무법자 `0.6 + 3·edge`, 부관 `0.3 − 3·edge`.
    기본값이 보안관 편 쪽으로 기운 것은 일부러다. 양쪽을 고르게 치면 배신자의 지문이 찍혀
    모두의 표적이 된다 (7인 시뮬레이션에서 배신자 승률이 절반으로 떨어졌다)
  - 무법자가 다 떨어지면 → 부관 정리, 마지막에 보안관
  - 무법자가 살아 있는 동안 보안관을 죽이면 진다. 목숨 1 인 보안관 앞에서 광역 카드 금지

## 측정

```bash
npm run simulate -- --games 100 --players 7
```

역할별·난이도별 승률에 더해 두 가지를 찍는다.

- **같은 편 오사율**: 같은 편을 겨냥한 개인 공격 / 전체 개인 공격 (난이도 × 역할)
- **역할 추정**: 차례마다 모든 생존자가 감춰진 역할을 맞힌 비율과 실제 역할에 준 평균 확률.
  7인 중 난이도끼리 80판에서 잰 값 (적중률 / 실제 역할에 준 평균 확률):

  | 깊이 | 1~2 라운드 | 3 라운드~ |
  |---|---|---|
  | `public` (행동을 안 읽음) | 50% / 0.41 | 54% / 0.47 |
  | `direct` (하) | 60% / 0.51 | 75% / 0.71 |
  | `full` (중·상) | 63% / 0.53 | 79% / 0.76 |

  초반에는 모두가 어림짐작으로 쏘니 차이가 작고, 판이 흐를수록 벌어진다.
