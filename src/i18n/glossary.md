# 번역 용어집

모든 en·it 번역은 이 표를 따른다. 새 용어는 여기에 먼저 적는다. it 는 공개 배포 전에 원어민 검수를 받는다.

| 한국어 | English | Italiano |
|---|---|---|
| 뱅! | BANG! | BANG! |
| 빗나감! | Missed! | Mancato! |
| 맥주 | Beer | Birra |
| 보안관 | Sheriff | Sceriffo |
| 부관 | Deputy | Vice |
| 무법자 | Outlaw | Fuorilegge |
| 배신자 | Renegade | Rinnegato |
| 사거리 | range | distanza |
| 장비 | equipment | equipaggiamento |
| 손패 | hand | mano |
| 더미 / 버린 더미 | deck / discard pile | mazzo / scarti |
| 판정 | draw! (check) | estrai! |
| 탈락 | eliminated | eliminato |
| 생명 | life points | punti vita |
| 턴 | turn | turno |
| 금덩이 | gold nugget | pepita |
| 캐릭터 | character | personaggio |
| 능력 | ability | abilità |
| 이벤트 | event | evento |
| 확장판 | expansion | espansione |
| 도감 | codex | enciclopedia |
| 설정 | settings | impostazioni |
| 닫기 | Close | Chiudi |
| 확인 / 취소 | OK / Cancel | OK / Annulla |

카드·캐릭터·이벤트 이름은 공식 이름을 쓴다 (en: 공식 영문판, it: dV Giochi 원판). `data/*.ts` 의 `name` 이 기준이다.
